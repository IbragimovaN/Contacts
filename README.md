# Contacts (учебный проект)

## Описание проекта
Приложение для управления контактами с реализацией на разных стейт-менеджерах. Проект разработан для глубокого изучения и сравнения подходов к управлению состоянием в React-приложениях.

## Ключевые особенности
- Три версии с разными стейт-менеджерами:
  - Redux (классическая реализация)
  - Redux Toolkit (RTK)
  - MobX (реактивное управление состоянием)

## Технологический стек
- **TypeScript**
- **React**
- **React Router**
- **Redux** (ветка `develop`)
- **Redux Toolkit** (ветка `rtk`)
- **MobX** (ветка `mobx`)
- **JSON Server** (моковый API)


## Функционал
- Выввод списка контактов
- Вывод списка групп
- Добавление контакта в избранные
- Поиск контактов по имени
- Сортировка по группе


## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск JSON Server (моковый API)
json-server --watch db.json --port 4000

# Запуск приложения
npm start
```
